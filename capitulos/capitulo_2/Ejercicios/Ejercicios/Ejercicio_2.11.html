2.11

  1. Falso. HTML5 no distingue entre mayúsculas y minúsculas en las etiquetas (no es sensible a mayúsculas), aunque el uso de minúsculas es una buena práctica recomendada.
  2. Verdadero. Los documentos de HTML5 pueden usar la extensión .htm o .html.
  3. Falso. La referencia a entidad de carácter para el carácter menor que (<) es &lt; (o &LT;), no &less;.
  4. Verdadero. El elemento <li> es el elemento de elemento de lista que se anida dentro de <ol> (lista ordenada) o <ul> (lista desordenada).
