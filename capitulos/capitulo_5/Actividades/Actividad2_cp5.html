5.2 Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por qué.

  1. La regla @font-face especifica que se utilizará una fuente incrustada cuando el documento se despliegue en una pantalla de computadora.
    Falso. Explicación: La regla @font-face permite descargar e incrustar fuentes personalizadas en la página web para cualquier medio de despliegue admitido, no únicamente para pantallas de computadora.
  2. Podemos usar gradientes en cualquier propiedad que acepte una imagen.
    Verdadero.
  3. Un gradiente horizontal cambia en forma gradual de arriba hacia abajo.
    Falso. Explicación: Un gradiente horizontal transiciona de izquierda a derecha (o viceversa); el que transiciona de arriba hacia abajo es un gradiente vertical.
  4. Podemos agregar líneas entre columnas mediante el uso de la propiedad column-gap.
    Falso. Explicación: La propiedad column-gap únicamente establece el espacio en blanco o separación entre columnas; las líneas divisorias se crean con la propiedad column-rule.
  5. La regla @media determina el tipo y tamaño del dispositivo en el que se despliega la página. Cuando el navegador examina la regla, el resultado es verdadero o falso. Los estilos de la regla se aplican sólo si el resultado es falso.
    Falso. Explicación: Los estilos declarados dentro del bloque @media se aplican únicamente cuando la condición evaluada resulta ser verdadera (true).
  6. Para agregar múltiples imágenes de fondo a un elemento, usamos la propiedad background-position para especificar en dónde colocar cada imagen mediante el uso del modelo de cajas.
    Falso. Explicación: La propiedad que delimita el área del modelo de cajas en la que se ubica la imagen (border-box, padding-box o content-box) es background-origin; background-position solo define las coordenadas o alineación inicial dentro de esa área.
