Actividad 9 (Ejercicio 7.9)

Identificación y corrección de errores en los siguientes segmentos de código[cite: 20]:
a)
if ( edad >= 65 ); document.writeln( "Edad es mayor o igual que 65" ); else document.writeln( "Edad es menor que 65" );
Error: Hay un punto y coma ; incorrecto al final de la condición del if[cite: 20], lo que hace que el bloque sea una instrucción nula y desconecta el else provocado un error de sintaxis[cite: 20]. También hay un punto y coma ; fuera de las comillas en la última instrucción[cite: 20].

Código corregido: if ( edad >= 65 ) document.writeln( "Edad es mayor o igual que 65" ); else document.writeln( "Edad es menor que 65" );
b)
var x = 1, total; while ( x <= 10 ) { total += x; ++x; }
Error: La variable total no está inicializada[cite: 20]. Al intentar realizar total += x, su valor resultará en NaN[cite: 20].

Código corregido: var x = 1, total = 0; while ( x <= 10 ) { total += x; ++x; }
c)
var x = 1; var total = 0; while ( x <= 100 ) total += x; ++x;
Error: Faltan las llaves { } para agrupar las instrucciones del ciclo while[cite: 20]. Sin llaves, solo total += x pertenece al ciclo, lo que provoca un ciclo infinito al no incrementarse x dentro de él[cite: 20].

Código corregido: var x = 1; var total = 0; while ( x <= 100 ) { total += x; ++x; }
d)
var y = 5; while ( y > 0 ) { document.writeln( y ); ++y; }
Error: La variable y se está incrementando (++y) en lugar de decrementarse (--y)[cite: 20], provocando un ciclo infinito ya que y siempre será mayor que 0[cite: 20].

Código corregido: var y = 5; while ( y > 0 ) { document.writeln( y ); --y; }
