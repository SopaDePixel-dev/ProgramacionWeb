Actividad 21 (Ejercicio 7.21)

Escriba una secuencia de comandos que muestre las potencias del entero 2 (2, 4, 8, 16, 32, 64, etc.) utilizando un ciclo infinito[cite: 21].
var potencia = 2; while ( true ) { console.log( potencia ); potencia *= 2; }
¿Qué ocurre cuando ejecuta este programa?
Al ejecutarse en un entorno como la consola del navegador, el ciclo entra en una repetición infinita que consume recursos de la CPU[cite: 21]. Conforme la variable potencia se multiplica por 2 continuamente, supera el límite máximo numérico de precisión de JavaScript (Number.MAX_VALUE) y comienza a imprimir Infinity[cite: 21]. Finalmente, el navegador dejará de responder o mostrará una advertencia de "Página no responde" sugiriendo forzar el cierre de la pestaña[cite: 21].
