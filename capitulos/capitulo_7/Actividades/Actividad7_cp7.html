Actividad 7 (Ejercicio 7.7)

Identificación y corrección de errores en los siguientes segmentos de código[cite: 20]:
a)
while ( c <= 5 ) {
    producto *= c;
    ++c;
Error: Falta la llave de cierre } para cerrar el bloque de la estructura while[cite: 20].

Código corregido: while ( c <= 5 ) { producto *= c; ++c; }
b)
if ( genero == 1 )
    document.writeln( "Mujer" );
else;
    document.writeln( "Hombre" );
Error: Hay un punto y coma ; innecesario e incorrecto justo después de la palabra clave else[cite: 20].

Código corregido: if ( genero == 1 ) document.writeln( "Mujer" ); else document.writeln( "Hombre" );
