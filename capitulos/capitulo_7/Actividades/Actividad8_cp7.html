Actividad 8 (Ejercicio 7.8)

¿Qué está mal en la siguiente instrucción de repetición while?[cite: 20]
while ( z >= 0 )
    suma += z;
Explicación del error: El valor de la variable de control z nunca disminuye ni cambia dentro del cuerpo del ciclo while[cite: 20]. Si z es mayor o igual a 0 al inicio, la condición siempre será verdadera y el ciclo se ejecutará de forma infinita (ciclo infinito)[cite: 20].

Código corregido (ejemplo decrementando z): while ( z >= 0 ) { suma += z; z--; // Se decrementa z para evitar el ciclo infinito }
