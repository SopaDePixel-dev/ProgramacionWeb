Sección 3.2.1: Elementos de estructura de página

HTML5 introduce varios elementos semánticos nuevos para estructurar el contenido de una página Web de manera más clara y significativa. Estos elementos permiten definir las diferentes partes de un documento, como encabezados, secciones de navegación, artículos independientes, barras laterales y pies de página, mejorando tanto la accesibilidad como la organización del código.

Importancia de la estructura semántica

El uso correcto de los elementos de estructura ayuda a los motores de búsqueda y a los lectores de pantalla a comprender mejor la jerarquía y relevancia del contenido dentro del sitio Web.
