Actividad 9.5

a) Definición de función con palabra clave incorrecta:

Error: method g() { document.writeln("Dentro del método g"); }
Solución: function g() { document.writeln("Dentro del método g"); }

Explicación: En JavaScript las funciones se definen con la palabra clave function, no con method.

b) Falta de instrucción de retorno en la función:

Error: function suma(x, y) { var resultado; resultado = x + y; }
Solución: function suma(x, y) { var resultado; resultado = x + y; return resultado; }

Explicación: Para devolver un valor calculado a quien llamó la función, se debe utilizar la instrucción return.

c) Parámetro o variable no declarada/redefinición:

Error: function f( a ) { document.writeln( a ); }
Solución: function f( a ) { document.writeln( a ); }

Explicación: La sintaxis de la función es válida. Sin embargo, si f(a) no recibe ningún argumento al invocarla, imprimirá undefined. Para evitarlo se debe pasar un valor al llamarla, o validar que a no sea indefinidad.
